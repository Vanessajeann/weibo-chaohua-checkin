# 微博超话签到 · LSPosed 测试版

在安卓手机上为一个微博账号签到已关注的超话。首次在模块内打开微博官方网页登录并确认 UID。开启自动签到后，微博标准版进入前台时会通知模块检查当天的签到状态。也可以直接在模块中点「立即签到」。

## 安装和首次使用

1. 安装模块 APK。手动签到入口要求 Android 8.1 或以上，自动触发还需要已启用、支持传统 Xposed API 的 LSPosed 和微博标准版。
2. 在 LSPosed 管理器启用「超话签到」，作用域勾选「微博」`com.sina.weibo`。强行停止一次微博，让框架在下一次启动时加载模块。
3. 从桌面打开「超话签到」，点「登录 / 切换微博账号」。在微博官方网页完成登录和可能出现的验证，然后点底部的「已在网页登录，确认此账号」。回到模块后核对 UID。
4. 点「立即签到」，查看本次签成、原已签和未识别的条目数。可以在微博的「我的超话」里核对结果。
5. 开启「打开微博时自动签到」，点「打开微博，检查触发」。返回模块查看「最近收到微博触发」的时间。即使今天已经手动签完，该时间也能用来检查模块是否生效。

## 运行方式

- 签到使用模块内确认的网页账号。微博 App 内切换账号后，模块仍使用原先确认的 UID。在模块内退出并重新登录即可换号。
- 每次任务先确认 UID，再分页获取关注列表。只处理可识别的签到按钮。微博拒绝请求或签到响应不确定时会停止，之后重新读取列表核对，已签条目会跳过。
- 每个北京时间自然日，完整处理成功后跳过后续自动签到。未完成时，至少间隔 30 分钟，再次打开微博可触发检查。手动按钮可以提前重试。任务由 Android 在网络可用时调度，省电设置可能让执行延后。当天一直未打开微博时无需等到次日，可在模块中手动执行。
- 登录状态保存在模块自己的 WebView。模块只向微博移动站发送签到请求。退出模块账号可清除本地网页登录状态并关闭自动签到。

## 构建

安装 JDK 17 或 21、Android SDK Platform 36 和 Build Tools 36.1.0，配置 `JAVA_HOME` 与 `ANDROID_HOME`。进入本目录运行：

```sh
./gradlew testDebugUnitTest assembleDebug
```

Windows 可使用 `gradlew.bat testDebugUnitTest assembleDebug`。可安装的本地构建产物在 `build/outputs/apk/debug/ChaohuaCheckin-debug.apk`，由本地调试证书签名。发布构建可运行 `assembleRelease` 后用自己的密钥签名。

## 验证范围

JVM 测试使用模拟响应覆盖账号验证、分页、去重、可签和已签状态、部分失败等路径。发布此测试版时，尚未在装有 LSPosed 和微博的真机上验证宿主触发、登录及真实签到。遇到问题时，可分别查看模块内的 UID、最近触发时间和最近一次签到结果。
